# Tâche 2.1 — Jeu de données synthétiques

**Auteur :** Illane SIDIBE, Membre 3 (IA et Big Data)

## Contenu
Données entièrement inventées, sans aucune personne réelle : 9 utilisateurs fictifs, 6 semaines,
431 tâches, 477 sessions et 83 reports (graine 42). Fichiers dans `data/synthetique/` : un CSV par
table (`utilisateurs`, `taches`, `sessions`, `reports`) et un fichier `jeu_donnees.json` qui les regroupe.

## Profils
| Profil | Comportement |
|---|---|
| regulier | Mêmes horaires, termine presque tout (96 % des tâches terminées) |
| irregulier | Horaires variables, reports fréquents (75 % des tâches terminées) |
| surcharge | Beaucoup de tâches, sessions qui se chevauchent, abandons (55 % des tâches terminées) |

## Champs (provisoires)
Les noms de champs sont provisoires, en attente du modèle de données du Membre 2 et du format
d'injection du Membre 1.

| Table | Champs |
|---|---|
| utilisateurs | id, profil, date_debut |
| taches | id, utilisateur_id, titre, priorite, duree_minutes, echeance, statut, semaine |
| sessions | id, tache_id, utilisateur_id, debut, fin, statut, duree_prevue_min, duree_reelle_min |
| reports | id, tache_id, utilisateur_id, ancienne_date, nouvelle_date, motif |

Valeurs : priorité `haute`, `moyenne` ou `basse` ; statut de tâche `a_faire`, `terminee` ou `abandonnee` ;
statut de session `terminee`, `interrompue` ou `manquee` ; dates au format AAAA-MM-JJ et heures
AAAA-MM-JJTHH:MM.

## Régénérer avec d'autres noms de champs
Modifier les listes `CHAMPS_*` en tête de `src/donnees_synthetiques.py`, puis :

    python -m src.donnees_synthetiques --sortie data/synthetique --semaines 6 --graine 42

La graine rend le jeu reproductible : mêmes paramètres, mêmes données.

## Limite
Ce sont des données simulées : elles permettent de tester le code et les indicateurs, pas de
démontrer des résultats sur de vrais utilisateurs.
