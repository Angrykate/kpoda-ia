# Tâche 1.2 — Données transmises au fournisseur IA

Principe : minimisation. Seul ce qui est nécessaire à la décomposition est envoyé.

| Envoyé | Jamais envoyé |
|---|---|
| Texte de l'objectif saisi par l'utilisateur, après contrôle | Nom, prénom, pseudonyme de l'utilisateur |
| Contraintes générales utiles (échéance, durée disponible par jour) | Adresse e-mail, numéro de téléphone, adresse |
| Identifiants techniques de tâches (T1, T2...) | Âge, date de naissance, établissement, lieu |
| | Toute donnée relative à un mineur permettant de l'identifier |
| | Historique complet de l'utilisateur, profil, mot de passe, clé d'accès |

## Mesures
- Détection et masquage automatiques des e-mails et numéros de téléphone avant envoi (`src/confidentialite.py`, testé).
- L'application doit éviter de transmettre les noms ; si l'objectif en contient, ils sont à retirer côté application avant l'appel.
- La clé d'accès est stockée dans `.env`, jamais dans le dépôt.
- Les données de test sont synthétiques.

## Limites
Le masquage automatique ne reconnaît que les e-mails et les numéros. Les noms propres
et autres informations libres dans le texte ne sont pas détectés : c'est pourquoi la règle
côté application reste nécessaire, notamment pour les mineurs.
